# Support

## Reporting a bug or requesting a feature

Please open an issue on GitHub: https://github.com/moiseshernandez26/JoltAPI/issues

Include your JoltAPI and VS Code versions (`Help > About`), the steps to reproduce, and — if relevant — the contents of the Output panel for "JoltAPI" (`View > Output`, then select "JoltAPI" from the dropdown).

## Before filing an issue

- Check the [CHANGELOG](./CHANGELOG.md) — your issue may already be fixed in a newer version.
- Search [existing issues](https://github.com/moiseshernandez26/JoltAPI/issues) to avoid duplicates.

## Security issues

Please do not open a public issue for a security vulnerability. See the contact information on the [GitHub profile](https://github.com/moiseshernandez26) instead.

## Contributing

See [CONTRIBUTING.md](./CONTRIBUTING.md) for development setup and how to submit changes.
